# Kratos Beam Spline Mappers Benchmark

Benchmark and test-case data for developing and validating Kratos beam spline mappers.

Included directories:

- `Bending_Torsion_Beam_Test_Case`
- `Bending_Torsion_Beam_Test_Case_2nd`
- `FSI_mok_Test_Case`

The `FSI_mok_Test_Case` folder is kept as a clean runnable benchmark package:
it includes case inputs, scripts, notes, and compact result summaries, but not
large generated VTK fields or transient run caches.  See
`FSI_mok_Test_Case/README.md` for the exact run commands and retained-output
policy.
